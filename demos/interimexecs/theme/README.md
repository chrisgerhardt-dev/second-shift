# InterimExecs Public Clone theme

Installable WordPress theme for the Second Shift / GrayBeard LLC case study.

## Install

1. Copy this `theme/` folder into `wp-content/themes/interimexecs-clone/`.
2. Activate **InterimExecs Public Clone** in Appearance → Themes.
3. Create pages (About, Services, Our Approach, Contact, Case Studies) and assign the matching page templates.
4. Set a static front page. Create a Posts page named Blog.

## Guardrails

- Core WordPress only. No Tiny Frog proprietary PHP.
- No premium plugins.
- Contact form is staging-only and never sends mail.

The clickable static clone lives at `/demos/interimexecs/wp-clone/`.
